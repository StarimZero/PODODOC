# 🍇 Pododoc: 나만의 와인 추천 애플리케이션

Pododoc은 사용자의 와인 시음 기록과 평점을 기반으로 취향을 분석하고, 머신러닝을 통해 새로운 와인에 대한 평점을 예측하여 개인 맞춤형 와인을 추천해주는 안드로이드 애플리케이션입니다.

---

## ✨ 프로젝트 소개 (Motivation)

기존의 데이터베이스 기반 추천 시스템은 사용자의 섬세한 취향을 반영하는 데 한계가 있었습니다.  
Pododoc은 이러한 한계를 극복하고자, 사용자가 직접 기록한 데이터를 바탕으로 머신러닝 예측 모델과 유사도 측정 알고리즘을 적용하여 훨씬 정교하고 개인화된 와인 추천 경험을 제공하기 위해 시작되었습니다.  

이 프로젝트를 통해 Python 라이브러리 활용 능력과 데이터 분석, 그리고 머신러닝 모델을 안드로이드 애플리케이션에 통합하는 실전 경험을 쌓는 것을 목표로 합니다.

## 🚀 주요 기능 (Features)

- 🍷 와인 기록 및 평점: 사용자가 마신 와인에 대한 정보와 별점을 기록하고 관리합니다.  
- 🤖 평점 예측 모델: 사용자의 시음 기록을 학습한 머신러닝 모델이 아직 마셔보지 않은 와인의 예상 평점을 예측합니다.  
- 🔍 유사도 기반 와인 추천: 사용자가 높게 평가한 와인과 특성이 유사한 다른 와인들을 유클리드 거리(Euclidean Distance)를 이용해 찾아 추천합니다.  
- 📊 데이터 시각화: 사용자의 와인 취향(품종, 국가 등)을 분석하여 시각적인 그래프로 제공합니다.  

---

## 🛠️ 사용 기술 (Tech Stack)

### Backend & Data Science
- Python, Flask: 데이터 처리 및 예측 모델 서빙을 위한 API 서버 구축  
- Pandas, Numpy: 데이터 분석 및 전처리  
- Scikit-learn: 머신러닝 모델(평점 예측) 구현  
- Matplotlib, Seaborn: 데이터 시각화 라이브러리  

### Frontend & Mobile
- Android (Java): 네이티브 안드로이드 애플리케이션 개발  
- Retrofit2: 안드로이드와 Flask 서버 간의 HTTP 통신

## ⚙️ 설치 및 실행 방법 (Installation)

(이 부분은 저장소의 실제 구조에 맞게 수정이 필요할 수 있습니다)

### 1. 서버 실행
```bash
# 저장소 복제
git clone https://github.com/Seoptrike/Pododoc.git
cd Pododoc/server  # 서버 폴더로 이동

# 의존성 설치
pip install -r requirements.txt

# Flask 서버 실행
python app.py
```

### 2. 안드로이드 앱 빌드
- Android Studio에서 `Pododoc/android` 폴더를 엽니다.  
- 서버 IP 주소를 로컬 환경에 맞게 수정한 후 빌드 및 실행합니다.
